# remove_firebase

[![Powered by Mason](https://img.shields.io/endpoint?url=https%3A%2F%2Ftinyurl.com%2Fmason-badge)](https://github.com/felangel/mason)

The inverse of `add_firebase` — permanently deletes the Firebase Auth
infrastructure it added and reverts every file it wired:

```
lib/core/networks/firebase/                                        (deleted)
lib/core/networks/exceptions/firebase_auth_exceptions.dart          (deleted)
lib/features/auth/data/repository_impl/firebase_auth_repository_impl.dart  (deleted)

pubspec.yaml                          (firebase_core/firebase_auth removed)
android/settings.gradle.kts           (google-services plugin declaration removed)
android/app/build.gradle.kts          (conditional google-services apply removed)
lib/main.dart                         (Firebase.initializeApp() call + import removed)
lib/core/di/injection_container.dart  (firebaseDependencies() + its call + imports removed)
lib/features/auth/auth_exports.dart   (export line removed)
```

## Safety

- **Refuses to run** (not just warns) if `IAuthRepository` is currently
  registered as `FirebaseAuthRepositoryImpl` in
  `injection_container.dart` — deleting that class while it's still the
  active registration would break the build. Switch
  `authDependencies()` back to `AuthRepositoryImpl(dataSource: sl())`
  first, then re-run this brick.
- Requires `--confirm` (or answering "yes" to the interactive prompt) —
  without it, nothing is deleted; it only prints what *would* be deleted.

## Usage

```sh
mason make remove_firebase --confirm
```

Or interactively:

```sh
mason make remove_firebase
```
